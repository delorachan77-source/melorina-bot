# 📚 Melorina Bot - سیستم مدیریت کتاب

یک ربات پیشرفته و API کامل برای مدیریت کتاب‌ها با قابلیت‌های هوش مصنوعی، احراز هویت JWT و معماری SOLID

---

## ✨ قابلیت‌های اصلی

| دسته | قابلیت |
|------|--------|
| 📚 **مدیریت کتاب** | افزودن، حذف، ویرایش، جستجو، دانلود |
| 👤 **مدیریت کاربر** | ثبت‌نام، ورود، پروفایل، تغییر رمز |
| 🤖 **هوش مصنوعی** | خلاصه‌سازی با Gemini، ترجمه، تحلیل کتاب |
| 💰 **فروشگاهی** | اشتراک، پرداخت، کد تخفیف |
| ⚡ **عملکرد** | کش با Redis، صفحه‌بندی، Rate Limiting |
| 🔐 **امنیت** | JWT Authentication، CORS، CSRF |

---

## 🛠️ تکنولوژی‌ها

- **Backend:** Django 4.2 + Django REST Framework
- **دیتابیس:** PostgreSQL
- **کش:** Redis
- **احراز هویت:** JWT (SimpleJWT)
- **هوش مصنوعی:** Gemini AI
- **سرور:** Nginx + Gunicorn
- **مستندسازی:** Swagger/ReDoc
